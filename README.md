# PRAKTIKUM OOP GOATED  
Repositori koleksi soal praktikum mata kuliah Pemrograman Berorientasi Objek IF2010 di Teknik Informatika ITB semester 2 tahun ajaran 2024/2025. Praktikum ini pada dasarnya menguji konsep Object Oriented Programming (OOP). Materi tersebut terbagi menjadi dua bagian, masa sebelum UTS dan setelah UTS. Waktu awal kuliah hingga UTS menggunakan bahasa pemrograman C++ dengan cakupan materi:  
1. Konsep Kelas
2. Operator Overloading
3. Inheritance
4. Virtual 
5. Template dan Generics
6. Exception Handling  

Terdapat juga materi setelah UTS hingga akhir perkuliahan dengan bahasa pemrograman Java:  
1. OOP di Java
2. Inheritance
3. Interface
4. Generics
5. Exception
6. Multithreading
7. Reflection
